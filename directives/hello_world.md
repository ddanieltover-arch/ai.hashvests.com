# Hello World Directive

This directive is a simple SOP to demonstrate the 3-layer architecture.

## Goal
Print "Hello, World!" to the console and save the output to a temporary file.

## Execution Tool
- `execution/hello_world.py`

## Expected Output
- A console message.
- A file in `.tmp/hello_output.txt`.

## Steps
1. Run the `execution/hello_world.py` script.
2. Verify the output in `.tmp/hello_output.txt`.
