# Directive: Premium Landing Page Development

This SOP defines the standards for creating a high-converting landing page for Hashvests Inc, optimized for Facebook and Google Ads.

## Goal
Create a visually stunning, responsive landing page using HTML and Tailwind CSS that builds trust and drives registrations.

## Core Components
1. **Hero Section**: High-impact headline, clear value proposition (Access to 4,000+ assets), and primary CTA (Register Now).
2. **Value Props**: 24/7 Support, Quick Withdrawals, Secure Environment, Real-time Analytics.
3. **Markets Grid**: Visual representation of Forex, Stocks, Crypto, Metals, and Energies.
4. **Social Proof**: User testimonials/reviews and platform statistics ($91M+ transactions).
5. **Trust Indicators**: Security badges (SSL, DDOS protection), registration claims.
6. **Social Integration**: Floating or footer links to Telegram, WhatsApp, TikTok, etc.
7. **Live Chat**: Integration of Talk.to script.

## Technical Standards
- **Framework**: Tailwind CSS via CDN or local build.
- **Responsiveness**: Mobile-first design (Ads are often viewed on mobile).
- **Aesthetics**: Premium dark/financial theme, gradients, micro-animations.
- **Performance**: Optimized images and minimal scripts for fast loading.

## Execution Steps
1. Create `index.html` with Tailwind CSS structure.
2. Implement the design sections following the hierarchy of information.
3. Integrate the Talk.to script provided by the user.
4. Finalize styles and animations.
